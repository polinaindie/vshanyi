# Бренд-правила в UI

Джерела: `BRAND.md`, `.cursor/rules/brand.mdc`, `brand/tokens.css`.

## Тверді правила

1. **Колір** — тільки токени. Ніяких hex у компонентах.
2. **Жовтий** — подія, не оформлення. Максимум один жовтий акцент на canvas. Ніколи як тло чи декор.
3. **Форми** — `border-radius: 0`. Без тіней, градієнтів, скла.
4. **Світла база** — Paper / Beige / Ink ≈ 95% полотна. Суцільної темної теми немає.
5. **Volja Black** — тільки логотип.
6. **Акцент** — жирність і кегль, не колір.
7. **Порожнє поле** — зміст. Не заповнювати повітря декором.
8. **Фото** — документальні; підпис `місце · рік · тег`.
9. **Іконки** — контурні, прості.

## Мова інтерфейсу — архів

- Розділювачі — hairline 1px, не картки з рамками.
- Секції: `01 — ПРО НАС` + `ЩО МИ РОБИМО →`.
- Час як навігація: `9:00 · 2022 → 2026`.

## Тон

Спокійно, коротко, з гідністю. Без пафосу й емоційного тиску.
