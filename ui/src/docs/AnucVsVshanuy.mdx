# Craft vs характер

З [Anuc Home](https://www.anuchome.com/) беремо лише **рівень craft леяуту** (сітка, типи секцій, ритм). Характер бренду — повністю Вшануй.

## Тест

Якщо відкрити Anuc і цей Storybook поруч — має бути видно інший світ (архів дії vs lifestyle/wellness), а не рескіненний fork.

## Що спільне (craft)

- Багатоколонкова сітка з вертикальними guides
- Типи секцій: hero, numbered list, carousel, FAQ, form, image+text, footer
- Full-bleed media + текст у колонці + block CTA як механіка

## Що принципово інше

| Anuc (не повторюємо) | Вшануй |
|---|---|
| Білий lifestyle / «гармонія простору» | Теплий папір, музейний спокій архіву |
| Геометричні фігури (арка/коло) як айдентика | Символ — час `09:00` |
| Інтерʼєрні lifestyle-фото | Документальні свідчення |
| Мʼякий сервісний тон | Спокійний наказ до дії, архівна мова |
| Брендові акценти Anuc | Ink + один жовтий = подія |
| CTA як запис на консультацію | CTA як підтримка / дія памʼяті |

Не копіюємо шрифти, кольори, зображення й shape-айдентику Anuc.
