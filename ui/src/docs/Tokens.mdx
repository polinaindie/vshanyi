Канон: `brand/tokens.css`. У Storybook підключено `src/styles/tokens.css` (ті самі змінні, шляхи до шрифтів для Vite).

## Типографіка

| Роль | Token | Шрифт | Начерк |
|---|---|---|---|
| Лого | `--font-logo` | Volja (тільки лого) | 900 |
| Дисплей | `--font-display` | Piazzolla Light (як на головній) | `--weight-display` = 300 |
| Текст / UI | `--font-text` | Fixel | 400 / 500 / 600 |

Локальні файли з `fonts/` — ті самі, що на сайті (не Google Fonts).

Шкала: `--step--1` … `--step-5`. Leading: `--leading-display`, `--leading-text`.

## Простір (тиша)

`--space-1` … `--space-5`, `--space-silence` — пауза між великими блоками.

## Форма

`--radius: 0` · `--line` · `--line-muted` · `--grid-line`
