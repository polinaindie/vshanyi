# Система леяуту — архівна сітка

Колонки задають структуру; **видимі** лінії ділять тишу локально — не як обов’язковий шар на всю сторінку. Горизонтальна hairline і точкова вертикаль між колонками змісту; лінія не перетинає span-заголовок на двох+ колонках. Політика: `.cursor/rules/silence-division.mdc`.

## Правила

- Desktop: 4 колонки; mobile: 2
- Видимі лінії — `1px` (`--grid-line` / `--line-muted` / grey 20%), лише де є смисловий розріз (див. silence map)
- Між великими секціями — `--space-silence` і/або одна hairline, не густо
- Контент чіпляється до лівого краю колонки, не «плаває» по центру
- Без карток із тінню й радіусом — hairline і повітря

## Драматургія головної

1. Зупинись (Hero + час)
2. Хто ми (About / ImageText)
3. Практики (NumberedDirections)
4. Зроби сам (GuideCta)
5. Що працює (ArticleCards / PracticeCarousel)
6. Ти не сам (Partners)
7. Доєднайся (Footer CTA / Contact)

Компонент-примітив: **ArchiveGrid** у Foundations.
